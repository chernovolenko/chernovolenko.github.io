# Rudder work continued

Continued work on the rudder. Finally installed the counter weight but only after killing the two screws that attach via nutplates. The solution I found (after ordering new screws) was to use Boelube and a nice new JIS screwdriver. I started on riveting the spar & skins on 6/21. I still haven't riveted the trailing edge after Proseal, it's one of the last steps.
